# 预览、编辑与视觉验收

三种手段各管一件事，缺一不可：
- 自动检测找结构与运行问题；
- 实际看图判断信息与视觉；
- 在目标应用里操作，验证用户需要的编辑行为。

## 制作前和代表页

先继承沟通模式。方向明确、模板固定或局部修改时直接处理；方向不明确且有设计自由时，比较少量结构不同的方向，不只换色。内部探索无需自动成为用户审批。

挑能暴露风险的内容：长中文、复杂关系、密集数据、特殊字体、图片焦点、模板占位符或目标应用兼容性。新建双格式核对 HTML／SVG 与原生 PPTX 代表页；简单短稿可把完整初稿作为验证对象。不按页数机械增加样稿。

## 四层规则

- **底线**：事实和口径准确，关键条件可见，文字可读，对象符合编辑合同，约定格式正常使用。必须通过。
- **默认方法**：结论式标题、网格、少量强调色、直接标注、留白等，按场景调整。
- **设计自由**：构图、方向、字体、密度、用图与节奏可以不同，不必向配方看齐。
- **目标**：底线之上追求记忆点，见下文的“出彩检查”。达不到时说明差距，不算失败，也不为它牺牲底线。

诊断线索见 [anti-patterns.md](anti-patterns.md)。好设计不止一种，不用唯一风格或模型自评分代替看图判断。

## 实际检查顺序

1. 信息：对照策划与来源，检查证据、状态、数字、分母和例外；SVG／架构图的箭头确有相应关系。
2. 全套总览：看节奏、主次、一致性和适当变化。高冲击页按传播需要使用，不凑数量；固定公司模板也能通过。
3. 每页完整尺寸：标题断行、焦点、层级、图像、留白、边缘、遮挡、图例、单位、标点和投影可读性。灰度／模糊图只是辅助诊断。
4. 实际使用：HTML 离线、翻页、揭示、窄视口、打印；PPTX 重开、渲染与编辑；同时核对备注和必要链接。
5. 双格式：信息、条件、数据、关系与重点一致，无需像素完全一致；说明有意义的差异。
6. 修复：内容问题回策划，排版／实现问题回制作。复查受影响页面；共用数据、主题、字体变化覆盖全部受影响范围。

## 出彩检查（目标，不是门槛）

“没有重叠”“看起来整齐”只说明没有错误。底线通过后，有设计自由时用以下问题自查：

- **去品牌测试**：遮掉 logo、公司名和标题文字，这套页面能否和通用模板或常见的批量生成演示区分开？不能就回到视觉定调，加强母题、尺度与素材。
- **截图测试**：有没有 1–3 页值得单独截图分享？没有时，优先投入封面、核心结论或最强证据页。
- **模糊测试**：模糊到看不清字时，最显眼的形状是否正是策划的焦点？
- **灰度测试**：去色后层级是否仍然成立？做不到就说明过度依赖颜色。
- **精修**：边距与对齐按像素核对，大字和引号做光学对齐；没有孤字和行首标点，数字与单位不断开；全套标题位置、页码和来源小字的样式统一。

改进优先从尺度、构图、素材和文字质量入手，而不是加阴影、渐变和装饰。

公司模板任务不做去品牌测试，改为检查模板之内的精致度：是否完全对齐模板网格，层级是否比原稿清楚，图表与表格是否去掉了默认样式，有没有溢出或挤压。

## 编辑验证

按 [pptx.md](pptx.md) 定位具体页和对象。普通文字、自绘矩阵数字、组内说明、统计图和图片分别选实际目标，不用一个成功文本框代表全套可编辑。

副本修改 → 保存 → 重开 → 核对同一目标的预期值 → 渲染查看。图表同时验证缓存与内嵌工作表；连线、联动标签测试所需行为。测试标记不进入交付文件。

## 脚本与证据

```bash
python scripts/preview.py html build/index.html --out build/review/html --strict
python scripts/preview.py pptx build/deck.pptx --out build/review/pptx --edit-test --edit-targets build/edit-targets.json --strict
```

脚本生成逐页 PNG、总览、灰度／模糊图、报告和独立测试副本。打开看过才算视觉检查。

| 状态 | 意义 |
|---|---|
| passed／通过 | 执行并取得证据，只在报告覆盖范围内成立 |
| failed／失败 | 与要求不符，修复后重测 |
| not_run／未执行 | 尚未做或被跳过 |
| unsupported／工具不支持 | 当前方法不能覆盖，需换方法或说明限制 |
| not_applicable／不适用 | 本任务没有此要求，记录原因 |

同时标注是否必需。必需项未执行或不支持，不算完成；可交付阶段稿但明确缺项。严格模式只汇总覆盖的自动检查，人工检查保持未执行，由 Agent 在策划或验收记录中补实际看图与操作证据，不篡改自动结果。对象或字体存在不能单独证明行为和视觉正确。
