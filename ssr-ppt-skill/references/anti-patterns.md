# 视觉与表达问题诊断

以下是诊断线索，不是风格禁令。这里刻意写得具体，因为这些正是最常让演示显得廉价或像批量生成的做法，笼统的提醒很难改变结果。命中时先问：它在这页有没有内容或品牌上的理由？有就保留，例如品牌本身就是圆角卡片体系，或模板指定系统字体；没有、且造成重点不清、噪音、误解或使用障碍时就改。质量底线见 [visual-review.md](visual-review.md)。

## 构图

| 现象 | 问题 | 改为 |
|---|---|---|
| 每页都是“标题 + 三四张等宽卡片” | 所有信息权重相同，看不出重点，页页雷同 | 先选焦点，再按信息关系选构图：大字、主图、对比、关系图、编辑式分栏 |
| 每页顶部一排数字卡片，下面仍是几张要点卡片 | 页页雷同；数字和结论的关系没有画出来 | 只在数字本身是重点的页使用；把关键数字放进主图，如比例条、对比条、图上标注 |
| 要点装进卡片，当作已经图示化 | 看起来整齐，关系和差异仍要靠逐句读 | 先提取对象、关系和数字，用位置、连线、比例表达；卡片只用于确有意义的分组。见 [content-expression.md](content-expression.md#表达方式) |
| 箭头连接的框里是完整句子 | 箭头只是装饰，读者仍要读段落 | 框内写对象或动作短语，条件写在箭头旁，解释移到备注 |
| 全部居中对齐 | 缺少阅读起点，显得松散 | 左对齐挂网格；只有封面、金句等少数页有意居中 |
| 内容在页面中间漂浮，四周留出一样宽的空 | 留白没有方向，像是没排完 | 让主体贴近网格边或出血，留白集中在一侧形成呼吸 |
| 元素平均铺满页面 | 没有主次，也没有停顿 | 给焦点足够的视觉权重，次要信息缩小并靠边 |
| 连续多页同一构图、同一密度 | 节奏平，观众注意力下滑 | 按策划的能量标注交替；并列比较页除外 |
| 封面只是标题加 logo 加日期，居中 | 第一眼毫无记忆点 | 用超大排版、主视觉图或数据图形做封面 |
| 结束页只有“谢谢观看 / Thank You” | 浪费最后的注意力 | 放核心结论回顾、下一步行动或联系方式，延续视觉母题 |

## 卡片与装饰

| 现象 | 问题 | 改为 |
|---|---|---|
| 卡片左侧一道彩色竖条 | 最典型的模板痕迹 | 用留白、细线分隔或编号建立分组 |
| 处处圆角加阴影 | 廉价的“UI 套件”感，层级被阴影淹没 | 全套只选一种形状语言（直角细线，或小圆角无阴影）；阴影只用于真实的层叠关系 |
| 卡片里套卡片、边框套边框 | 视觉噪音 | 外层用留白分组，内层取消边框 |
| 每张卡片顶部一个圆形色底图标 | 模板化，图标也不传递信息 | 删掉图标，用编号、关键词或数据作为卡片起点 |
| 毛玻璃、发光、霓虹描边到处用 | 廉价的科技感 | 只在配方明确需要时用于一两个元素 |
| 背景里漂浮的模糊色块、散落的点阵和圆圈 | 与内容无关的填充 | 删除，或换成由主题提炼的母题图形 |

## 色彩

| 现象 | 问题 | 改为 |
|---|---|---|
| 默认的紫→蓝渐变（如 `#6366F1`→`#8B5CF6`）、青紫霓虹，与主题和品牌都无关 | 最常见的“AI 生成感”，也常压住文字 | 从内容与品牌定颜色；渐变只在确有作用时用，色相相邻、不压文字 |
| 渐变填充的文字 | 可读性差，廉价 | 实色文字，用尺度和字重强调 |
| 所有元素同等强调，强调色到处出现 | 主次消失，强调失效 | 强调只给真正的重点；配色起点可参考 60／30／10，大面积品牌色按品牌规范处理 |
| 彩虹色数据系列、每根柱子一种颜色 | 颜色不承载含义 | 非重点用灰，重点用强调色；同一指标全套同色 |
| 浅灰小字放在白底上 | 读不清 | 正文对比度至少 4.5:1 |

## 字体与文字

| 现象 | 问题 | 改为 |
|---|---|---|
| 文字没有层级，断行与间距失控 | 难读、缺少重点 | 先调整尺度与排版，再决定是否换字体；模板和系统字体可保留 |
| 没有模板或品牌约束，却全套只用系统默认字体的单一字重 | 层级平、气质普通 | 至少用字重和尺度拉开层级；有设计自由时按 [typography.md](typography.md) 选字体搭配并嵌入 |
| 标题和证据无法区分，例如标题与正文字号相差不到约 1.5 倍 | 阅读顺序不清 | 综合字号、字重、位置、留白建立层级；起点见 typography 的字号阶梯 |
| 中文加大字距装“高级” | 松散难读 | 中文大标题字距 0 至 -0.02em |
| 用全大写英文做装饰（如 INTRODUCTION） | 空洞的装饰词 | 删除，或换成有信息的编号与章节名 |
| “背景介绍”“项目概述”“总结与展望”这类标题 | 没有信息量 | 写成观点或具体主题，如“三个城市贡献了七成新增客户” |
| 每条要点都是“关键词：解释”的格式，每页刚好三条 | 机械凑数 | 按实际信息组织；需要两条就写两条 |
| “赋能”“打造闭环”“全方位”“助力” | 空话 | 写具体动作、对象和数字 |

## 图标与图片

| 现象 | 问题 | 改为 |
|---|---|---|
| emoji 当图标 | 风格失控，在 PPTX 与不同系统中显示不一 | 用统一的线性图标集内联 SVG，或不用图标 |
| 给每个要点配一个图标 | 图标成了噪音 | 只在图标确实帮助识别时使用 |
| 混用不同风格的图标 | 不统一 | 全套一个图标集、一种线宽 |
| 握手、齿轮、灯泡、地球、芯片、数字雨等图库隐喻 | 陈词滥调 | 用真实的产品、场景、人物或数据图形 |
| 生成图中出现乱码文字、多余手指、塑料质感 | 一眼假 | 重新生成或改用排版表达；见 [imagery.md](imagery.md) |
| 图片被拉伸，或只为填空而放 | 廉价、分散注意力 | 按比例裁切；没有合适素材时用排版表达 |

## 硬套配方与原型

| 现象 | 问题 | 改为 |
|---|---|---|
| 为填满原型的栏位凑出条目，或删掉放不下的必需内容 | 内容被版式绑架 | 按内容改原型，或自定构图 |
| 为了做大数字页挑一个不重要的数字，为了做矩阵硬造两个维度 | 形式误导理解 | 回到这一页真正要说的结论 |
| 配方原样照搬，没有主题母题，换个主题也能直接用 | 不同主题长成一个样子 | 结合主题改编色彩、母题与尺度；都不贴切就自定方向 |
| 全套每页都机械地对应一个原型，各页之间缺少统一的视觉语言 | 像原型样本的拼盘 | 原型只提供起点，全套统一按视觉定调执行 |

## 数据

| 现象 | 问题 | 改为 |
|---|---|---|
| 3D 图表、透视饼图 | 扭曲比例 | 平面图表 |
| 饼图切片过密或差异难辨 | 难以比较 | 按任务考虑排序条形、分组或明细表 |
| 默认网格线、边框、图例全保留 | Office 默认样式感 | 按 [charts.md](charts.md) 去掉无用元素，改为直接标注 |
| 数字没有单位、期间或口径 | 不可信 | 单位、期间和口径写在标题、副标题或轴标题中 |
