# 图片、生成图、图标与图形

图像是让演示“惊艳”的主要来源之一，也是最容易显得廉价的地方。每张图都要承担具体作用：展示主体、说明情境、提供证据或建立气质。没有作用就不放，宁可用排版表达。

## 来源与优先级

1. **用户素材**：产品图、现场照片、团队照片、品牌图库。优先使用，裁切和调色可以调整，但不改变事实含义。
2. **可用的真实素材**：有明确许可的图库（如 Unsplash、Pexels 的许可条款），或用户指定的来源。在 `sources.md` 记录来源与许可。
3. **图像生成**：环境提供图像生成工具时使用，适合主视觉、氛围与概念示意。生成图不能冒充真实证据、真实产品或真实人物，必要时标注“示意”。
4. **代码生成的图形**：由主题或数据生成的抽象图形、母题图案、几何构成（见下文）。
5. **纯排版**：超大字、大编号、引文。没有好素材时，这往往比一张平庸的图片更有力。

## 生成图提示词规范

先为全套写一段固定的**风格锚**，附在每个提示词末尾，保证全套像同一位摄影师或插画师的作品：

```text
风格锚示例：editorial photography, soft natural window light, muted warm palette with deep teal shadows,
subtle film grain, 35mm lens, shallow depth of field, calm and minimal composition
```

每张图的提示词包含：

- **主体与场景**：具体到物、人、动作和环境，避免“未来科技”“商务人士”这类空泛描述。
- **构图与留白**：写明主体位置和留给文字的空白区。例如“主体位于右侧三分之一，左侧大面积干净的暗部留给标题”。
- **比例**：与版位一致。全出血用 16:9，半页用 4:5 或 1:1，竖条用 9:16。
- **色调**：用配方的色彩描述（暖白、墨黑、陶土色等），让图片和页面融为一体。
- **排除**：`no text, no letters, no logos, no watermark`。图中出现的文字几乎总会是乱码。

流程：

1. 先生成 1–2 张校准风格，确认和页面放在一起成立后再批量生成。工具支持时固定 seed 或参考图，保持一致。
2. 逐张检查乱码文字、多余或畸形的手指、透视错误、塑料质感、品牌标识，以及与事实冲突之处。有问题就重新生成，不靠裁切遮掩。
3. 避免过饱和 HDR、无意义光效、“科技蓝”全息界面、漂浮几何体这类生成图的典型套路。

## 处理手法

全套照片要统一色温、饱和度、明暗与颗粒。可用的手法：

| 手法 | 用途 | HTML 实现 | PPTX 实现 |
|---|---|---|---|
| 统一调色 | 不同来源的照片融为一套 | CSS `filter`（saturate、contrast、sepia 微调），或预处理 | 用 Pillow 预处理后插入 |
| 双色调 | 强烈的品牌感、统一杂乱素材 | 灰度图加 `mix-blend-mode: multiply / screen` 色层 | 用 Pillow 预处理 |
| 颗粒 | 胶片感，消除渐变色带 | 叠加低不透明度的 SVG `feTurbulence` 噪点 | 叠加预渲染的半透明噪点 PNG |
| 文字区遮罩 | 文字落在图片上仍可读 | 只覆盖文字一侧的线性渐变，从背景色到透明 | 带透明度渐变的独立矩形 |
| 出血与特写裁切 | 增加张力和尺度感 | `object-fit: cover` 配 `object-position` 控制焦点 | 预先按版位比例裁好再插入 |
| 抠图出框 | 主体压在标题或边框之上，形成层次 | 透明 PNG 叠在文字层之上 | 透明 PNG 置于文字之上 |
| 形状蒙版 | 拱形、圆形、切角框，呼应配方 | `clip-path` 或 `border-radius` | 预处理成带透明背景的 PNG |

- 文字遮罩只调到能读清为止，不要给整张图盖一层 50% 的黑。
- 主体的视线或运动方向朝向页面内部或文字，不要朝向页面外。
- 用图片的局部特写（材质、手、细节）制造高级感，比完整但平淡的全景更有效。
- PPTX 用的图片按版位尺寸的 2 倍左右导出，单张一般压到 1MB 以内。HTML 内联图片注意总文件体积，照片用 JPEG 或 WebP。
- 抠图需要透明 PNG：用户素材、已有工具或可用的去背工具。做不到时不要用粗糙的边缘冒充。

## 没有素材时

- **超大排版**：把关键词、数字或章节编号放大到 300px 以上，裁切出血，本身就是主视觉。
- **母题图形**：把视觉母题画成图形，例如物流的路线折线、金融的刻度、城市的建筑网格、自然主题的等高线。保持配方色彩，作为背景时降低对比。
- **数据即图形**：用真实数据画出的线条、点阵或条带做封面或章节页的图形；比抽象装饰更有意义，也更难被模仿。
- **色块构成**：用两三块颜色分割页面，配合大字，形成海报感（适合 R1、R7）。

HTML 中这些图形用内联 SVG 或 CSS 绘制，不依赖外部资源；PPTX 中用原生形状绘制，或预渲染为 PNG 后作为背景图片，同时保持文字原生。

## 图标

- 只在图标确实帮助识别时使用，不给每个要点配图标，不用 emoji。
- 全套只用一个线性图标集：Lucide、Tabler Icons、Phosphor 等开源图标集（使用前确认许可）。统一线宽（24px 尺寸下 1.5–2px）、尺寸和颜色。
- HTML 中把 SVG 源码内联。拿不到图标源文件时，用基本形状自己画简洁的几何图标，不引用 CDN。
- PPTX 中以 SVG 或高分辨率 PNG 插入。图标属于图片，不需要原生可编辑；颜色要在导出前就设定好。

## 标志

使用官方提供的标志文件，不拉伸、不改比例、不改颜色，品牌规范允许时才使用单色版本。在深色背景上使用反白版本，没有反白版本时放在浅色底块上。
