# 图标、配图、SVG 插画与图形

图像是让演示“惊艳”的主要来源之一，也是减少文字最直接的办法：一张贴切的图、一排统一的图标，往往比一段说明更快被看懂。它也最容易显得廉价，所以每张图都要承担具体作用：展示主体、说明情境、提供证据、帮助识别或建立气质。

这里说的“图”首先是图片、图标和示意插画。图里基本不放字：说明用原生文字放在图旁，不做塞满文字的信息图。

## 图标

图标让表格、卡片、流程和数字更好认，也让页面更精致。

- **来源**：优先用本 Skill 自带的 `assets/icons/`（Lucide 线性图标子集，ISC 许可，名称和含义见 `INDEX.md`）。需要的图标不在其中时，从同一套 Lucide 补充（保留许可），或用基本形状画同样线宽的简洁图标；不混用其他风格的图标集。
- **用在哪里**：
  - 表格的表头或行首：每列／每行一个图标，提示这一列讲什么；
  - 卡片和要点的标题前：一张卡一个图标；
  - 流程、链条和架构的节点：图标加短标签，比方框里写句子更好读；
  - 关键数字旁：小图标说明数字属于什么；
  - 章节页、封面：放大的单个图标可以作为视觉母题。
- **统一**：全套一个图标集、一种线宽、一两种颜色（通常主色，强调处用强调色）。同一层级的图标同样大小，与旁边文字的字高或行高对齐。
- **贴切**：图标要和内容对应，例如工厂对应生产、货车对应物流、门店对应零售、盾牌对应风控。找不到贴切的就不用，不用无关图标凑数。
- **不用 emoji**：在 PPTX 和不同系统中显示不一。
- **PPTX**：`pptx_kit` 的 `deck.icon(slide, "factory", x, y, size=32, color="1E5AA8")` 把图标做成一个原生形状，可在 PowerPoint／WPS 里改颜色、缩放而不糊。图标较大（约 96px 以上）时可把 `stroke` 调细到 1.5。
- **HTML**：把 SVG 源码内联，`stroke="currentColor"` 让图标跟随文字颜色；不引用 CDN。

## 配图：网络图片与生成图

讲主体、场景或产品时配图，让观众先看到“是什么”。

| 作用 | 选择 |
|---|---|
| 证明真实人物、产品、设备或现场 | 用户原图，或经核实的真实来源；不能用生成画面冒充证据 |
| 说明行业、场景与氛围（供应链、门店、工厂、城市） | 上网搜索授权合适的照片或插画，或用专用生图工具生成 |
| 展示产品、物件与细节（面料、拉链、鞋服、货车、包装） | 搜索合适的图片，或用 SVG 画示意插画（见下节） |
| 强调一句结论 | 排版、文字或数据本身可能足够 |

搜索网络图片：

1. 优先用明确允许商用的图库，例如 Unsplash、Pexels、Pixabay，以及标明 CC0／CC BY 的来源；也可用用户指定的来源。
2. 打开候选原图核对主体、分辨率、水印、来源和许可，不能只看缩略图。带水印、来源不明或许可不清的不用。
3. 在 `sources.md` 记录图片链接、作者或提供方、许可，以及用在哪一页；CC BY 等需要署名的，在页脚或备注署名。
4. agent 没有搜索或下载工具时，改用 SVG 插画、自带图标或排版表达，并在策划中说明。

公司内部材料中的人物、logo、真实客户的门店等，只用用户提供的图片；不从网上找来当作对方的照片。

## SVG 示意插画

没有合适图片，或需要突出某个产品细节时，用 SVG 画示意插画：例如一卷面料、一条拉链、一只运动鞋、一辆货车、一间门店，或把它们组合成上游工厂—仓库—门店的场景。

- **画法**：扁平或线性风格，与全套色彩一致；可直接组合自带图标，再加底色块、阴影块等简单形状。保持简洁，不追求写实。
- **图里少字**：插画只用短标签，必要的说明放在图旁的原生文字里。
- **不是信息图**：插画表现“是什么、长什么样、在什么场景”；数量和关系由图表或流程图表达，不把它们混进插画。
- **PPTX**：`deck.svg_picture(slide, "build/supply.svg", x, y, w, h)` 用 PyMuPDF 把 SVG 按版位的 2 倍分辨率转成 PNG 插入；SVG 源文件留在构建目录，修改后重新生成。PyMuPDF 支持常见的形状、路径、渐变和透明度，不支持滤镜等复杂效果，插入后看图确认。
- **HTML**：直接内联 SVG。

## 生成图提示词规范

环境提供图像生成工具时可用，适合主视觉、氛围与概念示意。先为全套写一段固定的**风格锚**，附在每个提示词末尾，保证全套像同一位摄影师或插画师的作品：

```text
风格锚示例：editorial photography, soft natural window light, muted warm palette with deep teal shadows,
subtle film grain, 35mm lens, shallow depth of field, calm and minimal composition
```

每张图的提示词包含：

- **主体与场景**：具体到物、人、动作和环境，避免“未来科技”“商务人士”这类空泛描述。
- **构图与留白**：写明主体位置和留给文字的空白区。例如“主体位于右侧三分之一，左侧大面积干净的暗部留给标题”。
- **比例**：与版位一致。全出血用 16:9，半页用 4:5 或 1:1，竖条用 9:16。
- **色调**：用配方的色彩描述（暖白、墨黑、陶土色等），让图片和页面融为一体。
- **排除**：`no text, no letters, no logos, no watermark`。图中出现的文字几乎总会是乱码。

流程：

1. 先生成 1–2 张校准风格，确认和页面放在一起成立后再批量生成。工具支持时固定 seed 或参考图，保持一致。
2. 逐张检查乱码文字、多余或畸形的手指、透视错误、塑料质感、品牌标识，以及与事实冲突之处。有问题就重新生成，不靠裁切遮掩。
3. 避免过饱和 HDR、无意义光效、“科技蓝”全息界面、漂浮几何体这类生成图的典型套路。
4. 生成图不能冒充真实证据、真实产品或真实人物，必要时标注“示意”。

## 处理手法

全套照片要统一色温、饱和度、明暗与颗粒。可用的手法：

| 手法 | 用途 | HTML 实现 | PPTX 实现 |
|---|---|---|---|
| 统一调色 | 不同来源的照片融为一套 | CSS `filter`（saturate、contrast、sepia 微调），或预处理 | 用 Pillow 预处理后插入 |
| 双色调 | 强烈的品牌感、统一杂乱素材 | 灰度图加 `mix-blend-mode: multiply / screen` 色层 | 用 Pillow 预处理 |
| 颗粒 | 胶片感，消除渐变色带 | 叠加低不透明度的 SVG `feTurbulence` 噪点 | 叠加预渲染的半透明噪点 PNG |
| 文字区遮罩 | 文字落在图片上仍可读 | 只覆盖文字一侧的线性渐变，从背景色到透明 | 带透明度渐变的独立矩形 |
| 出血与特写裁切 | 增加张力和尺度感 | `object-fit: cover` 配 `object-position` 控制焦点 | 预先按版位比例裁好再插入（`deck.picture` 默认裁切填满） |
| 抠图出框 | 主体压在标题或边框之上，形成层次 | 透明 PNG 叠在文字层之上 | 透明 PNG 置于文字之上 |
| 形状蒙版 | 拱形、圆形、切角框，呼应配方 | `clip-path` 或 `border-radius` | 预处理成带透明背景的 PNG |

- 文字遮罩只调到能读清为止，不要给整张图盖一层 50% 的黑。
- 主体的视线或运动方向朝向页面内部或文字，不要朝向页面外。
- 用图片的局部特写（材质、手、细节）制造高级感，比完整但平淡的全景更有效。
- PPTX 用的图片按版位尺寸的 2 倍左右导出，单张一般压到 1MB 以内。HTML 内联图片注意总文件体积，照片用 JPEG 或 WebP。
- 抠图需要透明 PNG：用户素材、已有工具或可用的去背工具。做不到时不要用粗糙的边缘冒充。

## 没有素材时

- **图标母题**：把一个贴切的图标放大，作为封面或章节页的主视觉。
- **超大排版**：把关键词、数字或章节编号放大到 300px 以上，裁切出血，本身就是主视觉。
- **母题图形**：把视觉母题画成图形，例如物流的路线折线、金融的刻度、城市的建筑网格、自然主题的等高线。保持配方色彩，作为背景时降低对比。
- **数据即图形**：用真实数据画出的线条、点阵或条带做封面或章节页的图形；比抽象装饰更有意义，也更难被模仿。
- **色块构成**：用两三块颜色分割页面，配合大字，形成海报感（适合 R1、R7）。

HTML 中这些图形用内联 SVG 或 CSS 绘制，不依赖外部资源；PPTX 中用原生形状绘制，或预渲染为 PNG 后作为背景图片，同时保持文字原生。

## 标志

使用官方提供的标志文件，不拉伸、不改比例、不改颜色，品牌规范允许时才使用单色版本。在深色背景上使用反白版本，没有反白版本时放在浅色底块上。
