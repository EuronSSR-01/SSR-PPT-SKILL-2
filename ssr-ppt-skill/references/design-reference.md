# 按任务选择设计参考

用来扩展视觉判断，不是每次必须通读的风格目录；不声称覆盖行业某个百分比。六项判断可以合并写在视觉定调中。

| 判断 | 实际用途 |
|---|---|
| 沟通目标 | 观众要理解、比较、记住或采取什么行动，决定重点与密度 |
| 视觉方向 | 将严谨、亲和、编辑感、摄影主导、工业或未来感写成具体字体、材料、色彩和构图 |
| 流派与传统 | 借用适合的构成／排印原则，不按名称整套照搬 |
| 文化语境 | 结合具体地区、文字、图像与使用习惯，避免文化标签等于固定风格 |
| 设计方法 | 网格、排印、信息设计、叙事、视觉修辞、品牌系统和动态表达 |
| 媒介条件 | 观看距离、尺寸、现场／独立阅读、交互、静态与编辑限制 |

## 可借用的原则

| 参考方向 | 可借用 | 使用判断 |
|---|---|---|
| 瑞士／国际主义排印 | 网格、非对称排版、清晰层级 | 密集信息、品牌或编辑任务；允许内容突破网格 |
| 包豪斯／新字体排印、现代主义 | 功能优先、几何构成、排印与形态统一 | 产品、教育、文化；避免把几何当装饰堆叠 |
| 风格派／构成主义 | 方向、平面、尺度与节奏 | 强概念画面；文字与数据仍须易读 |
| 极简与当代编辑设计 | 精简、留白、精确字阶和主图 | 信息已有取舍；极简不能省掉关键事实 |
| 艺术与工艺、新艺术、装饰艺术 | 材料感、线条、有组织的装饰 | 文化、品牌与叙事；装饰须与主题有关 |
| 后现代／新波、孟菲斯、实验排印 | 打破整齐、意外组合、活跃节奏 | 有表达自由时探索；保留阅读顺序 |
| 大众印刷、波普、拼贴与街头视觉 | 对比、图像并置、印刷肌理 | 活动、文化和公众传播；确认图像使用许可 |
| 信息设计与数据新闻 | 证据、直接标注、比较尺度与注释 | 数据与研究，先检查口径再设计 |
| 品牌与导视系统 | 稳定语义、识别、组件与空间秩序 | 公司模板和持续更新材料 |
| 摄影／插画主导 | 场景、情绪与视觉叙事 | 分清事实证据、概念与装饰 |

这些方向会交叉，也不全是同一层级的历史流派。地域传统按具体任务研究，数字手法如扁平、拟物、3D、动态与沉浸效果属于媒介表达选择，可与不同原则组合。

从观众任务开始，选少量有用原则，再转换成可执行画面语言。例：需要解释运输链路，可用编辑式层级＋线路母题＋真实现场照片；公司模板中则沿用其字体和色彩，在约束内重排信息。配方库只是现成组合，自定方向是正常路径。
