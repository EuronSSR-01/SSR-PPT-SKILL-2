# 逐页策划

策划稿把内容和页面表达连接起来。它必须能指导实际制作，也让用户容易定位修改。

## 记录方式

使用 `planning.md`，开头记录受众、用途、总页数、交付格式、视觉约束、沟通方式与表达方式（图示优先／图文均可，注明是用户选择还是默认）。区分现场讲述与独立阅读：现场页突出可扫读的重点，独立阅读页保留理解所需的解释。精确页数限制下先重组内容，不自行加页。

新建或整体美化时，按 [art-direction.md](art-direction.md) 的格式补一段视觉定调，记录概念、所选配方与改编、参考调性、色彩、字体、字号、网格、形状语言、图片与图标处理、高潮页和禁用项。公司模板任务写明内容区（取自哪个版式或占位符、左右边距）。较长演示标出用于方向比较与内部校准的代表页，比较后写下取舍理由；局部修改沿用现有定调。用一份逐页列表同时承担大纲和策划，避免复制多份文档。只有代码需要结构化输入时才另建 `deck-plan.json`，保持它与策划稿同步。

每页包含以下信息，可用短句：

- **页码与标题**：准确对应成品。标题可为主题或有证据支撑的观点，不强制每页都写成结论。
- **能量**：高冲击 / 标准 / 密集 / 呼吸，含义见 [art-direction.md](art-direction.md) 的“节奏”。
- **页面目的 / 核心信息**：观众看完应该理解什么。
- **主要内容与依据**：正文、数据、引用及来源标识；待核实内容单独标记。
- **视觉焦点与阅读顺序**：第一眼看到什么，如何继续读到证据与解释，哪些细节应弱化。一个焦点可以是一组需要同时比较的对象。
- **版式与视觉**：主次面积、对齐关系、留白及素材处理，以及选择图表、图片、流程或卡片的理由。写可执行的构图，不只写“左文右图”。参考了 [layouts.md](layouts.md) 中的原型时注明编号与改动（如“参考 L05，单位改放数字下方”），没有参考的写“自定”。
- **图片与图标**：用哪些图标（`assets/icons` 的名称）、配什么图（网络图片的来源与许可，或 SVG 插画画什么）。图示优先时写明哪些文字由图承担了。
- **文字去处**：页面上留哪些文字（结论、关键数字、短标签、改变结论的条件），哪些放备注。
- **可编辑要求**：哪些文字、表格、图表、示意图必须是 PPTX 原生对象。
- **讲述衔接**：只有理解顺序需要时记录上一页与下一页的连接。

小任务可以把这些内容合为一个段落；不要为了填字段增加无用信息。用户只要求大纲时交付大纲，不提前制作两种格式。

关于材料本身的说明（材料没写什么、某个数字为什么不画、口径如何推算）写在策划稿或备注里，不放到页面上给观众看。公司模板里的示例文字（日期、部门名、示例标题）不是材料，列为待确认。

## 示例

```markdown
## 03｜新增客户是增长的主要来源

能量：高冲击（全套第一个高潮页）。
目的：解释收入变化来自哪里。
内容：沿用用户表格中的新客、存量客户增购和流失数据；单位、期间与表格一致。[S02]
焦点与阅读：先看总变化的大数字，再沿贡献图理解变化来源；期间与单位直接可见，详细计算放备注。
版式：参考 L05 大数字页与 L06 主图加结论，两者合在一页。总变化用 180px 展示字，占左侧约三分之一；贡献图占其余主体区域。新客贡献用强调色，其他项目用灰色弱化但保持可读。大数字与图表顶部对齐，通过留白分组，不额外套卡片。选用贡献图以解释加减关系。
图片与图标：三个来源各配一个图标（user-check 新客、repeat 增购、circle-x 流失），放在图表类别名前；不配照片。
文字去处：页面留标题、总变化数字和三个类别标签；计算过程放备注。
可编辑：标题和正文用文本框；贡献图须保留原生数据。若现有工具不支持该图型，选择能说明同一关系的原生图表并说明取舍。
衔接：下一页讨论新增客户来源。
```

示例不是待填入的事实。真实任务只有材料支持该结论时才使用。

把全套页标题、能量和构图并列查看：
- 铺垫是否支持核心证据，高潮页是否放在叙事的关键位置；
- 是否连续多页能量与构图都相同；
- 密集页之后是否需要呼吸页帮助消化；
- 同一句话或同一组数字是否在多页重复。

并列比较页可以保持相同构图。方向比较和代表页预览后的调整回写本稿；成品改动后（加页、删页、调换顺序、改结论）同步更新本稿，双格式继续使用同一内容和数据。

## 来源

`sources.md` 记录来源标识、资料名称、链接或文件位置、相关日期/数据口径和所支持的页码；网络图片另记作者或提供方与许可。只保存当前演示用到的资料。

对应来源放入 PPTX 页面备注。HTML 在相关页脚或可访问的来源区域保留链接。需观众直接看到的限制和口径仍写在页面上，不仅藏在备注中。
