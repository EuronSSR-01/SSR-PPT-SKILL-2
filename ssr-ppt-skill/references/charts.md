# 数据图表与表格

图表常常是演示中最能体现专业度的页面，也最容易留下 Office 默认样式的痕迹。先核对数据与阅读任务，再决定是否需要图表。可以突出结论，但反例、口径、基线和关键条件不能为了美观被删。

## 数据保真（文字页同样适用）

计算前检查：
- 比例的分子确属分母子集，范围和时间口径一致，分母非零；不能把两个无对应关系的计数相除。
- 构成图类别互斥且覆盖声明的整体；不完整则明确“其余／未知”，有重叠不画成互斥占比。
- 汇总先处理重复记录；加权平均按真实权重，不能对比例简单平均代替总体比例。
- 缺失、未统计、不适用与零分别表达；不擅自补零。
- 比较期间必须可比（长度、范围、基准适当），同比当然是不同年份，不能要求时间点完全相同。
- 实际、计划、申请、预测、建议与待验证显式区分，条件与来源能追溯。
- 精简时保留单位、小数口径、日期和影响判断的例外；手写图外数字和说明随数据变化一起检查。

没有依据不计算、推断因果或补数据。数据不足可展示已知事实与缺口，不能美化成确定结论。

## 选型

先明确要比较的是大小、变化、构成、分布还是关系，再选图型。

| 要表达 | 首选 | 备注 |
|---|---|---|
| 类别大小比较 | 条形图（类别名较长时用横向）、柱形图 | 按数值排序，除非类别本身有顺序 |
| 时间趋势 | 折线图；期数少时用柱形图 | 系列不超过 4 条，其余灰化或拆成小倍数 |
| 构成占比 | 100% 堆叠条形、环形图（不超过 4 份，中心放总数或结论数字） | 超过 5 份的饼图改用排序条形图 |
| 增减分解 | 瀑布图 | 原生图表不支持瀑布图时，用透明底座系列的堆叠柱实现 |
| 分布 | 直方图、点图、箱线图 | |
| 两个变量的关系 | 散点图，标注关键点 | |
| 单一关键指标 | 大数字配对比值与迷你趋势线 | 例如 96–160px 数字 + “▲ 12% 同比” |
| 排名变化 | 斜率图 | |
| 多组同结构比较 | 小倍数：相同坐标的多个小图 | |

以下数量与尺寸是起点，不是硬性限制；按实际标签密度与读数任务选择。

## 美化默认值

两种格式通用：

- **删除**：图表外框、绘图区背景、次要网格线、3D、阴影、渐变填充、与直接标注重复的图例。
- **网格线**：默认删除。需要读数时只保留极淡的水平主网格（浅色背景约 `#E5E5E5`，0.5–0.75pt）。
- **坐标轴**：有数据标签时可隐藏数值轴；类别轴的标签用正文字体 14–16px（11–12pt），颜色用次文字色；轴线细或不画。
- **颜色**：
  - 支持结论的系列或数据点用强调色，其余用中性灰（浅背景 `#B8B8B8` / `#D0D0D0`，深背景 `#4A4A4A` / `#5E5E5E`）。
  - 同一指标全套同色；序列色不超过 5 个。
  - 用灰度测试确认强调仍能分辨。
- **柱宽与间距**：柱宽大于柱间距（PPTX 间距宽度约 40–80%）；柱子不加描边、不加渐变。
- **折线**：2–3px（1.5–2.25pt）。重点线加粗并加端点圆点，在线的末端直接写系列名，代替图例。
- **数据标签**：只标关键点，或全部标注但字号要小。数字格式统一（千分位、相同小数位），单位只在标题、副标题或轴标题中写一次。
- **标题与注释**：
  - 标题写结论，副标题写指标、单位与期间，来源放左下角 12–13px。
  - 用一条细线加一小段文字标出关键事件，例如“4 月提价”。这是让图表讲故事最有效的手法。
- **基线**：柱形图和条形图从 0 开始；截断坐标轴时明确标示。不用面积、透视或不合理的截轴夸大差异。

## 表格

- 区分表头、关键列与辅助信息。用行距、对齐和少量细分隔线建立层级；不默认每格上色或加粗边框。
- 数字右对齐并使用等宽数字，小数位一致；文字左对齐。
- 关键行或关键单元格用强调色文字或浅底色标出，全表只强调一处到两处。
- 表头可用字重、细线或色面建立层级，按整体视觉和可读性选择。
- 行数多时去掉竖线，只保留横向细线或隔行极浅底色。
- 保留用户要求的行列。放不下时拆页，或把明细放到附录页，不压缩到不可读。

## HTML 实现

- 优先手写内联 SVG，精确控制每个元素，也不依赖外部图表库或 CDN。
- 用 `viewBox` 定义坐标，文字保持为真实的 `<text>`，使用页面字体并设置 `font-variant-numeric: tabular-nums`。
- 数据写在脚本中的数组里，由脚本生成 SVG；PPTX 也从同一份数据生成原生图表，保证一致。
- 可以加入描绘动画（折线用 `stroke-dashoffset` 描出，柱子从基线升起）。动画结束后的静态状态必须完整，并尊重减少动态效果的偏好。播放器的 `data-anim="draw"` 等入场效果见 [html.md](html.md)。

## PPTX 原生实现

按视觉与数据语义明确需要的样式，适合的默认值无需机械覆盖。

**PptxGenJS** 常用选项（以下名称已在 4.0.1 源码中核对；版本不同时以已安装版本为准）：

- 通用：`showLegend: false`、`showTitle: false`、`chartColors`、`valGridLine: { style: 'none' }` 或细浅色线、`catGridLine: { style: 'none' }`、`plotArea: { fill: { color } }`。
- 坐标轴：`valAxisHidden: true`、`catAxisLineShow: false`；`catAxisLabelFontFace` / `catAxisLabelFontSize` / `catAxisLabelColor`，数值轴使用对应的 `valAxis*` 选项。
- 数据标签：`showValue: true`、`dataLabelPosition`、`dataLabelFormatCode: '#,##0'`、`dataLabelFontFace` / `dataLabelFontSize` / `dataLabelColor`。
- 柱形：`barGapWidthPct: 50–80`；横向条形用 `barDir: 'bar'`，配合 `catAxisOrientation: 'maxMin'` 让排序从上到下。
- 折线：`lineSize`、`lineDataSymbol`、`lineDataSymbolSize`。
- **单点高亮**：用逐点着色，不要为配色增加假系列、把缺失值改零或扭曲底层数据。
  - PptxGenJS 条形／柱形图（4.0.1 实测）：保持单个系列，让 `chartColors` 给每个数据点一个颜色，例如 `chartColors: values.map((_, i) => i < 2 ? 'E8590C' : 'CBC5B8')`。底层数据仍是一个真实系列。
  - 这种做法下标签可以放在柱外（`dataLabelPosition: 'outEnd'`），并可配合 `valAxisMaxVal` 给标签留出空间。
  - 逐点着色会让图例按数据点列出，通常设 `showLegend: false`，改为直接标注。
- 数据标签颜色对全部数据点统一，选在背景上清楚的颜色（通常是次文字色）并放在柱外；放在柱内时要同时检查强调色和浅色柱上的对比度。

**python-pptx**：条形图和柱形图可以直接用 `scripts/pptx_kit.py` 的 `bar_chart`，它已按以上默认值处理，并通过自动编辑测试（见 [pptx.md](pptx.md)）。自己写时注意：

- `chart.has_legend = False`；`value_axis.has_major_gridlines = False`；`value_axis.visible = False`。
- 字体：`chart.font.size` / `chart.font.name`，中文需另写东亚字体。
- 间距：`plot.gap_width`。
- 逐点着色：`series.points[i].format.fill`。
- 数据标签：`plot.has_data_labels = True`，再通过 `plot.data_labels` 设置 `number_format` 与 `font`。

两种工具都要渲染后核对：标签有没有重叠或被截断，字体是否被替换，颜色和排序是否与数据一致，数据标签是否和数值匹配。不能以“API 已设置”作为验收依据。
