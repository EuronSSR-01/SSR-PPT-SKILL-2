# 风格配方库

配方是整理好的视觉方向推荐，不是模板。每套开头都写明适用与不适用：内容合适就优先参考，不合适就不用。配方可以修改、混搭，也可以参照它们的写法自建新方向，清单不封闭。用户品牌或模板存在时，配方只提供版式手艺（网格、尺度、手法），颜色和字体服从品牌。

## 如何使用

1. **判断**：
   - 按内容目的、观看场景（现场大屏 / 独立阅读）和受众，对照各配方的适用与不适用，挑出 1–2 套贴切的候选。
   - 拿不准时，在代表页阶段把两套都做出来比较（见 [visual-review.md](visual-review.md)）。
   - 都不贴切时不选，按 [art-direction.md](art-direction.md) 的方法和设计数值自定方向，在视觉定调中写“自定”。
2. **改编**：选用后结合主题调整，不原样照搬，否则不同主题的演示会长得一样。通常至少调整三处：
   - **色彩**：强调色换成品牌色，或从主题素材中取色（产品、照片、行业惯用色），保持配方的明暗结构与色彩比例。
   - **母题**：从内容中提炼一个贯穿全套的视觉母题。例如物流取路线折线，茶饮取叶脉与汤色，金融取刻度与 K 线，城市更新取建筑立面网格。母题出现在封面、章节页和至少一个高潮页。
   - **尺度与密度**：按实际文字量和数据复杂度调整字号阶梯和网格，不让配方的“理想页面”挤压真实内容。
3. **混搭**最多两套：一套为主（决定字体、网格、色彩），另一套只借一个手法，例如在数据新闻风格中借用瑞士风格的超大编号。
4. 配方中的字体按 [typography.md](typography.md) 获取、嵌入与回退；字体不可用时用回退方案，不悄悄换成默认字体。
5. **自建**：自定的方向在视觉定调里按同样的项目写清楚（适用理由、色彩、字体、网格、标志性手法、禁忌），全套统一执行。

## R1 瑞士编辑网格

- **适用**：战略汇报、设计或咨询提案、年度总结，需要显得理性克制的场合。
- **不适用**：需要温度和亲和力的主题（公益、医疗关怀）；以照片情绪为主的故事；品牌色彩丰富且不允许减色。
- **气质**：理性、清晰、有设计感。
- **参考调性**：Josef Müller-Brockmann 海报、Pentagram 提案、Vignelli 标识手册。
- **色彩**：背景 `#F4F4F0`，主文字 `#111111`，次文字 `#5C5C5C`，细线 `#CFCFC8`，强调 `#E4002B` 或克莱因蓝 `#1F3FFF`（二选一）。数据：强调色 + `#111111` + `#9A9A94` + `#CFCFC8`。
- **字体**：标题 思源黑体 Heavy / HarmonyOS Sans Black；正文 思源黑体 Regular；数字与西文 Inter。
- **网格与尺度**：12 栏，外边距 72px。封面字 160–220px，页标题 48–56px，正文 22px。
- **标志性手法**：超大字贴边或出血；页面顶部细线配小号编号与章节名；大面积空白中放极小的注释；元素严格挂在网格线上，左对齐不居中。
- **图片**：黑白或高对比，矩形硬边。
- **禁忌**：圆角卡片、渐变、阴影、居中排版、多于一个强调色。

## R2 暗场发布会

- **适用**：产品发布、愿景、路演中的关键页，大屏现场演讲。
- **不适用**：信息密集、需要阅读的汇报；需要打印或在明亮环境投影（深底看不清）；没有好的产品素材或主视觉。
- **气质**：聚焦、戏剧化、自信。
- **参考调性**：Apple 发布会、Nothing 产品发布。
- **色彩**：背景 `#050506`，次级面 `#16161A`，主文字 `#F5F5F7`，次文字 `#86868B`。强调从产品或品牌取一个高亮色（示例 `#2997FF` 或 `#FF6A2B`）。光感只用于主视觉区域，例如强调色 15–20% 不透明度的径向光。
- **字体**：标题 HarmonyOS Sans Bold / MiSans Semibold；正文 Regular，不小于 22px；数字 Inter。
- **网格与尺度**：一页一个想法。关键页文字不超过约 25 个汉字；大字 96–200px。
- **标志性手法**：产品大比例特写配低调布光；一句话配一张图；黑底巨大数字配细字号单位；关键句逐步揭示。
- **图片**：去背产品图置于黑底；没有产品时用材质与光影特写。
- **禁忌**：密集表格（移到附录并改用浅色阅读版式）、多色、装饰图标。

## R3 数据新闻

- **适用**：经营分析、行业研究、调研报告，以图表为主的内容。
- **不适用**：数据很少的情感叙事；产品发布；需要强烈品牌氛围的场合。
- **气质**：可信、精确、耐读。
- **参考调性**：The Economist 图表页、FT Visual Vocabulary、NYT Upshot、澎湃美数课。
- **色彩**：背景 `#FBF9F4`（或 FT 式粉 `#FFF1E5`），主文字 `#1A1A1A`，次文字 `#666158`，网格线 `#E2DED5`，强调 `#D7263D`。数据系列 `#0F4C81` `#3C8DBC` `#9DB4C0` `#B5A88F`，非重点一律用灰。
- **字体**：标题 思源宋体 Bold；正文与图表 思源黑体；数字 Inter（表格用等宽数字）。
- **网格与尺度**：左对齐。标题即结论，40–48px，最多两行；副标题写指标、单位与期间；底部来源 13px。
- **标志性手法**：标题上方一枚短色块（如 48×6px 强调色）作为刊物标记；图表直接标注，用注释线标出关键事件；灰色衬托唯一强调系列；用小倍数图并列比较。
- **图片**：很少，以图表和地图为主。
- **禁忌**：3D、图例远离数据、每根柱子不同颜色、装饰插画。

## R4 日式杂志留白

- **适用**：生活方式品牌、文旅、设计作品、品牌故事，并且有高质量摄影。
- **不适用**：信息密集的汇报；需要强冲击和紧迫感的路演；没有好照片。
- **气质**：安静、精致、有呼吸感。
- **参考调性**：Casa BRUTUS、Kinfolk、无印良品、原研哉的设计。
- **色彩**：背景 `#F3F0E8`，主文字 `#2A2925`，次文字 `#7A766C`，细线 `#D8D3C7`。点缀色二选一：朱 `#9C3B2E` 或藏青 `#2E4057`，只用在极小面积。
- **字体**：标题 思源宋体 SemiBold；正文 思源宋体 Regular 或思源黑体 Light；西文小注 Cormorant Garamond 斜体。
- **网格与尺度**：外边距 96px 以上，留白占页面一半以上。标题 36–56px，靠位置与留白取胜，不靠字号。
- **标志性手法**：竖排标题或竖排小注；大幅摄影配一小段文字；页码与章节用小号西文；不对称版面。
- **图片**：自然光、低饱和、带颗粒，留出负空间；静物与细节特写。
- **禁忌**：粗重黑体大标题、高饱和色、图标。

## R5 东方当代

- **适用**：文化项目、非遗、茶酒、国潮品牌、城市文化。
- **不适用**：与传统文化无关的主题。“这是一家中国公司”本身不构成使用理由；科技产品和面向国际受众且没有文化关联的内容也不适用。
- **气质**：文化感、克制的东方审美。
- **参考调性**：朱赢椿、吕敬人的书籍设计；当代博物馆展陈版式。
- **色彩**：底色 `#EFE9DE` 或墨色 `#1E1D1B`（主文字取另一者），朱砂 `#A8322D`，黛青 `#2F4B53`；金 `#A88B5A` 只用于细线和小字。
- **字体**：标题 思源宋体 Heavy，或霞鹜文楷（更人文）；正文 思源宋体 Regular；数字用汉字数字或衬线数字。
- **网格与尺度**：大留白，标题可竖排；正文窄栏。
- **标志性手法**：竖排；印章式朱色小方块内反白字；极细界格与边框；用一个大字作为图形；构图留白如山水。
- **图片**：器物、材质、建筑局部，低饱和暖调。
- **禁忌**：祥云、回纹、龙纹、中国结等素材堆砌；大红大金铺满全屏；繁复花边。

## R6 工程蓝图

- **适用**：技术架构、研发方案、开发者产品、工程评审。
- **不适用**：以非技术受众为主的汇报（显得冷硬难懂）；情感叙事。
- **气质**：严谨、可信、工程感。
- **参考调性**：Stripe 文档、Linear 发布页、Vercel、工程图纸。
- **色彩**：
  - 深色版：底 `#0C1117`，面 `#141B24`，线 `#263241`，主文字 `#E6EDF3`，次文字 `#8B98A8`，强调 `#4CC2FF`，次强调 `#7EE0A1`。
  - 浅色版：底 `#F6F8FA`，文字 `#0D1117`，线 `#D0D7DE`，强调 `#0969DA`。
- **字体**：标题 思源黑体 Bold / HarmonyOS Sans Bold；正文 Regular；标注、编号与代码用 JetBrains Mono 或 IBM Plex Mono。
- **网格与尺度**：模块按真实层级对齐，间距倍数 8px。
- **标志性手法**：低对比点阵或细网格背景；模块用 1px 细线框配等宽小标签；连线带方向箭头且语义明确；局部放大镜头；步骤编号 01 / 02。
- **图片**：真实界面截图或终端片段，加细边框。
- **禁忌**：发光霓虹、电路板 / 数字雨 / 地球之类“科技感”背景图、紫蓝渐变。

## R7 粗野海报

- **适用**：创意提案、活动、年轻品牌、内部动员。
- **不适用**：严肃汇报；金融、医疗等需要稳重可信的场合；年长或保守的受众。
- **气质**：大胆、年轻、有态度。
- **参考调性**：瑞士朋克海报、Bauhaus 海报、Gumroad、Spotify Wrapped。
- **色彩**：选两个高饱和撞色加黑白。示例：柠檬黄 `#F2E94E` + 黑 `#0B0B0B` + 白 + 电光蓝 `#2B59FF`；或番茄红 `#FF4A1C` + 奶油 `#F6EBDD` + 黑。
- **字体**：标题 得意黑 或 思源黑体 Heavy，超大且紧凑（行高 0.95，字距 -0.02em）；正文 思源黑体 Medium；数字 Bebas Neue / Oswald。
- **网格与尺度**：可以打破网格，但每页只破一处。
- **标志性手法**：大字出血裁切；色块分割整页；3–4px 粗黑边框配无模糊的硬投影；贴纸或标签式小元素；少量斜排。
- **图片**：高对比抠图，与色块叠压。
- **禁忌**：柔和渐变、毛玻璃、细弱字重；不用于严肃汇报。

## R8 静奢品牌

- **适用**：高端品牌、地产、酒店、珠宝时尚、高端活动。
- **不适用**：信息量大的分析；务实或预算导向的主题（显得浮夸）；没有质感素材。
- **气质**：高级、克制、有仪式感。
- **参考调性**：Aesop、Hermès 年报、高端酒店手册。
- **色彩**：象牙 `#F6F2EA` 或深炭 `#1B1A18`（主文字取另一者），次文字 `#8A8378`，香槟 `#B59B74` 只用于细线与小字。
- **字体**：中文 思源宋体 Light / Regular，大标题也用细字重；西文 Playfair Display / Bodoni Moda / Cormorant Garamond；小号大写西文字距 0.2em。
- **网格与尺度**：可以居中对称；元素极少，留白极大。
- **标志性手法**：大幅质感摄影（材质、光影）；细线与小字；成对的中英文标题。
- **图片**：暗调或柔光，强调材质。
- **禁忌**：粗黑体、图标、密集信息、阴影卡片、高饱和色。

## R9 温暖人文

- **适用**：教育培训、公益、医疗健康、HR 与组织文化、社区。
- **不适用**：需要强烈权威感与严谨感的技术或金融汇报；高端奢华定位。
- **气质**：亲和、可信、有温度。
- **参考调性**：Airbnb、Headspace、Mailchimp 的品牌视觉。
- **色彩**：底 `#FBF6EF`，主文字 `#2D2A26`，次文字 `#6E665C`，陶土 `#C65D3B`，橄榄 `#6D7B3B`，雾蓝 `#7A9CB8`，浅色块 `#F1E6D6`。
- **字体**：标题 阿里巴巴普惠体 Bold / OPPO Sans Bold；引文用霞鹜文楷点缀；正文 Regular。
- **网格与尺度**：舒展，正文行高 1.7。
- **标志性手法**：全套统一的大圆角色块（如 24px）；真实人物摄影（自然光、真实场景）或统一风格插画；引言页用大引号配文楷。
- **图片**：真实、自然、有人。
- **禁忌**：冷硬科技蓝、图库假笑摆拍、堆砌装饰插画。

## R10 咨询商务

- **适用**：管理层汇报、战略分析、尽调、项目复盘，需要结论导向和高信息效率。
- **不适用**：品牌故事；产品发布；需要情绪感染力的演讲。
- **气质**：专业、结论导向、高效。
- **参考调性**：McKinsey、BCG、Bain 的报告版式。
- **色彩**：底 `#FFFFFF`，主文字 `#0B1F33`，次文字 `#5B6878`，线 `#D9DEE5`。主色 `#0B3D91` 或品牌色；强调 `#00A19A` 只用于与结论相关的部分。数据：主色深浅三阶加灰。
- **字体**：标题 思源黑体 Bold 36–44px，写成结论句，不超过两行；正文 Regular 18–22px；数字 Inter。
- **网格与尺度**：左侧结论、右侧证据，或上结论下证据；页脚放来源与注释。
- **标志性手法**：动作标题贯穿，只读标题就能读懂全套；瀑布图、2×2、议题树等结构化图表；章节跟踪条标出当前位置。
- **图片**：基本不用。
- **禁忌**：装饰图片、图标墙、空洞标题。这套最容易滑向平庸，出彩必须靠标题质量、图表质量和精确排版。

## R11 光感科技

- **适用**：AI 或互联网产品发布、科技公司路演，并且有真实的产品界面可以展示。
- **不适用**：传统行业或政务汇报；没有产品界面可展示；需要打印的场景。
- **气质**：前沿、流畅、有产品感。
- **参考调性**：Stripe 首页、Linear、Vercel Ship、Raycast。
- **色彩**：底 `#07080C`，面 `#11131A`，主文字 `#F2F3F5`，次文字 `#8E95A3`。光源色从品牌取两个相邻色相（示例 `#FF7A45`→`#FFC145`，或 `#3EE6C0`→`#2F80FF`），不要默认紫→蓝。
- **字体**：标题 MiSans / HarmonyOS Sans Semibold，字距 -0.01em；正文 Regular；数字与代码 JetBrains Mono。
- **网格与尺度**：大标题、少文字、产品界面占主体。
- **标志性手法**：
  - 渐变只作为背景中的大面积柔光（模糊 120px 以上，不透明度不超过 35%）或主视觉，并叠加颗粒避免色带。
  - 面板用 `rgba(255,255,255,.08)` 的 1px 细边框。
  - 产品界面截图做主视觉。
- **图片**：真实产品界面优先。
- **禁忌**：渐变文字、每张卡片都发光、霓虹描边、到处用玻璃拟态。

## R12 学术研究

- **适用**：学术答辩、科研汇报、技术报告。
- **不适用**：商业路演；面向大众的传播。
- **气质**：严谨、清楚、可复核。
- **参考调性**：Nature / Science 图版、Edward Tufte、Distill.pub。
- **色彩**：底 `#FFFFFF`，文字 `#1F2328`，次文字 `#57606A`，线 `#D0D7DE`，强调 `#B31B1B`。序列色用 viridis（`#440154` `#3B528B` `#21918C` `#5EC962` `#FDE725`）或单色深浅。
- **字体**：标题 思源黑体 Bold；正文 思源宋体或思源黑体；西文 Source Serif / Source Sans。公式在 HTML 中用 MathML 或内联 SVG，在 PPTX 中用原生公式或说明其编辑范围。
- **网格与尺度**：一页一个研究问题或结论；图注完整。
- **标志性手法**：规范图号与图注（图 1｜……）；小倍数对比；引用编号；局部放大细节。
- **图片**：重绘论文图，不贴模糊截图。
- **禁忌**：装饰背景与图片、超出需要的色彩。

## R13 纪实影像

- **适用**：案例故事、公益、调研现场、品牌纪录，并且有真实的现场照片。
- **不适用**：没有真实照片（用生成图冒充纪实不可接受）；以数据为主的分析。
- **气质**：真实、有力、有情绪。
- **参考调性**：国家地理、Magnum 图片社、纪录片字幕。
- **色彩**：以照片为主。底 `#0E0E0E`，文字 `#F2F2F2`，次文字 `#A3A3A3`，强调从照片中取一个颜色。
- **字体**：标题 思源宋体 Bold 或思源黑体 Medium（字幕感）；正文 Regular；时间、地点用等宽小字。
- **网格与尺度**：照片全出血，文字落在暗部，像字幕一样克制。
- **标志性手法**：全出血照片配字幕式文字；时间 / 地点 / 人物等元信息小字；黑场引言页；用全景、中景、特写三种景别组成照片组。
- **图片**：真实现场照片。需要生成图时明确标注为示意，不冒充纪实。
- **禁忌**：图库摆拍、过度调色、文字压在主体上。
