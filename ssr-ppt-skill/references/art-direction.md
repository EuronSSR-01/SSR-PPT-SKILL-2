# 视觉定调与页面设计

用于新建演示或美化版式。已有模板、品牌与用户指定的参考优先；仅改文字或数据时沿用现有视觉体系，不重新设计整套。

## 目标

做出让人记住的演示，而不只是没有错误的演示：

- **有辨识度**：在任务和品牌允许的范围内形成一致的视觉语言；公司模板的准确、精致呈现同样是好设计。
- **重点有力**：核心结论、证据或场景值得加强时投入视觉设计，不规定高潮页数量。
- **有节奏**：高冲击页、标准内容页、密集阅读页与呼吸页按叙事交替。
- **有精度**：普通内容页可以平静，但对齐、层级、字体和数字处理必须精确。

视觉服务于内容。主次、尺度、构图、素材与适当效果共同表达目标，不把某种效果本身视为好坏标准。底线通过后，用 [visual-review.md](visual-review.md) 的“出彩检查”自查是否真的让人记住。

## 确定方向

1. 先由目标、受众、内容和品牌确定方向；需要起点时查 [style-recipes.md](style-recipes.md)，需要理解流派、方法与文化关系时查 [design-reference.md](design-reference.md)。可直接自定，不必先试遍配方。
2. 选用配方时结合主题改编：色彩来自品牌或主题，从内容中提炼视觉母题，按真实内容量调整尺度。自定方向时同样需要概念、母题和明确的设计数值。
3. 读取 [typography.md](typography.md) 确定字体搭配与获取方式；按需参考 [anti-patterns.md](anti-patterns.md) 诊断表达问题。
4. 在 `planning.md` 写下视觉定调。需求明确时自主决定，不要求用户先挑风格；候选方向拿不准时，在代表页阶段并排比较（见 [visual-review.md](visual-review.md)）。

“高级、极简、科技感”不能指导制作。视觉定调至少写到下面的具体程度：

```markdown
## 视觉定调
- 概念：像一份经济学人特刊，暖白纸面、宋体结论标题、灰色证据中只有一抹品牌橙
- 配方：R3 数据新闻（主），借用 R1 的超大章节编号
- 改编：强调色改为品牌橙 #F26B1D；母题为物流路线折线，出现在封面、章节页和第 7 页
- 参考调性：The Economist 图表页、FT Big Read
- 色彩：bg #FBF9F4｜ink #1A1A1A｜ink-2 #666158｜line #E2DED5｜accent #F26B1D｜data #0F4C81 #9DB4C0 #B5A88F
- 字体：标题 思源宋体 Bold；正文 思源黑体 Regular / Medium；数字 Inter（表格用等宽数字）；PPTX 字体策略：稳妥（见 typography.md）
- 字号（px，1280×720）：展示 160｜标题 44｜小标题 26｜正文 22｜标注 14
- 网格：12 栏，外边距 80，栏距 24，间距倍数 8
- 形状语言：直角、无阴影、1px 细线分隔
- 图片：仓库与车队的真实照片，统一偏暖低饱和，裁成横幅
- 高潮页：P1 封面、P5 核心结论、P9 最强证据
- 禁用：渐变、圆角卡片、图标墙
```

示例只用来说明需要写到什么程度，不能当作默认主题。没有参考配方时，“配方”一行写“自定”，其余各项照常写清楚。

## 设计数值

没有品牌规范时，从以下数值出发，按配方和内容调整，并把最终值写进视觉定调。

- **画布与网格**：默认 1280×720。可从外边距 64–96px、12 栏、栏距 24px、8px 间距单位起步；模板、长文或特殊构图按内容调整。同类元素共用对齐线，页面之间标题位置保持一致。
- **字号**：按 [typography.md](typography.md) 的字号阶梯。根据阅读顺序建立足够清楚的层级，不规定每页字号比。
- **色彩比例**：60／30／10 可作配色起点，并非面积配额；大面积品牌色也可成立。背景不必是纯白，可用偏暖或偏冷的近白，或深色。
- **色彩角色**：定义背景 / 表面 / 主文字 / 次文字 / 弱化 / 线 / 强调 / 数据系列，全套只按角色用色，不临时取新颜色。HTML 写成 CSS 变量，PPTX 写成常量。
- **对比度**：正文对背景至少 4.5:1，大字至少 3:1；彩色数据还要用标签或形状区分，不能只靠颜色。
- **形状语言**：圆角、描边、阴影三者各选一种做法并全套统一。阴影只用于真实的层叠关系。

## 节奏

在有助于安排讲述时，可用以下节奏描述；不要求所有类别都出现：

| 能量 | 用途 | 处理 |
|---|---|---|
| 高冲击 | 封面、核心结论、最强证据、章节开场 | 一个想法，极大的尺度反差，主视觉或超大排版 |
| 标准 | 主要论证 | 明确焦点，配一组支撑证据 |
| 密集 | 数据明细、对比表、需要独立阅读的信息 | 编辑式层级，可以小字号但仍可读 |
| 呼吸 | 章节过渡、引言、停顿 | 大留白，极少文字 |

- 相同构图用于并列比较和稳定阅读；出现机械重复、重点不明时再改变密度与构图，不按固定页数换版。
- 密集页之后考虑安排一个呼吸页或高冲击页。
- 高潮页在策划时就确定，制作时优先投入。

## 根据内容构图

每页按以下步骤确定构图：

1. 先选最需要被看见的内容。焦点不等于每页都放巨大的数字，也可以是一组对比、一张照片或一条清楚的关系链。
2. 给焦点足够的面积、位置或对比，辅助信息围绕它组织。
3. 按理解顺序安排视线：第一眼看到什么，接着读到哪里，哪些细节应当弱化。

[layouts.md](layouts.md) 收录了 22 个常见页面任务的版式原型，每个都写明了适用与不适用，可以作为构图起点。原型可以修改、组合；没有合适的就按上面三步自定构图，效果好的自定版式可以在全套中复用。

用共同的字体、色彩语义与对齐关系保持一致，用面积、位置、密度与素材制造变化。只有分组确实有意义时才使用卡片；连续比较页可以保留相同布局。

## 排版与留白

详细规则见 [typography.md](typography.md)。

- 先排最长的标题和最密的正文，验证字号、文本框和行距，再批量制作。
- 标题按语义断行，避免孤字，不拆开数字与单位，行首不出现句读标点。
- 同级内容共用基线和间距；检查文本框内边距，不能只对齐外框。数字列按位数或小数点对齐。
- 留白用于分组、突出与停顿，要有方向，不要四周均匀漂浮。图片可以出血，重要文字与数据留在安全区内。
- 内容拥挤时，先删冗词、重组，或在允许的页数内拆分，最后才考虑缩小字号。

## 图片、图形与数据

- 图片、生成图、图标与无素材时的图形处理见 [imagery.md](imagery.md)。
- 图表与表格的选型和美化默认值见 [charts.md](charts.md)。

两者的共同底线：

- 素材必须承担具体作用，事实性图片不能用虚构画面冒充。
- 标题、正文和数据单独制作；不生成带整页文字或图表的图片，再当作可编辑 PPTX 交付。

## 双格式与动效

HTML 和 PPTX 共享核心构图、视觉焦点与证据，但允许按各自的文本度量微调位置和换行。先验证主要视觉能在两种格式中成立。复杂装饰可以做成局部图片，但不能因此把需要编辑的对象变成图片。

HTML 动效用于强化叙事：入场依次出现、逐步揭示、数据描绘等（播放器支持见 [html.md](html.md)）。遵守减少动态效果的系统偏好；打印和静态 PPTX 保留完整信息。先检查静态页面，不用动画掩盖层级与构图问题。
