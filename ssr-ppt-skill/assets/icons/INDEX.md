# 图标索引

Lucide 1.48.0 的线性图标子集（ISC 许可，见同目录 LICENSE）。24×24 网格、2 单位线宽、圆角端点，颜色由使用处决定。

- PPTX：`deck.icon(slide, "factory", x, y, size=32, color="1E5AA8")`，生成可改颜色的原生形状。
- HTML：内联 SVG 源码，`stroke="currentColor"` 跟随文字颜色。
- 需要的图标不在这里：可从同一套 Lucide 图标补充（保留许可），或用基本形状画同样线宽的简洁图标；不混用其他风格。
